# 伊斯蘭世界：區域差異與文化影響｜高中生自學

## 開啟方式
- 解壓縮後，將整個 `islam_learning_site` 資料夾部署到任何靜態網站空間；以瀏覽器開啟 `index.html` 也可閱讀與作答。
- 無建置流程、伺服器依賴或外部資源。HTML、CSS、JavaScript 與圖片採相對路徑；整個資料夾放在網站子目錄仍可使用。
- 如瀏覽器的本機安全設定限制某些功能，請使用靜態網站伺服器開啟該資料夾。

## 測驗與互動
- 章節目錄跳轉、章節展開／收合、A 單選 5 題、B 配對 5 對、C 填空 1 格、D 圖片判讀 2 題。
- 題目皆標示為「模擬題，仿學測風格」，共 13 個計分項，每項答對 1 分、答錯或未作答 0 分。
- 未完成交卷時會列出未答題號，可選擇繼續作答或直接交卷；提交後才顯示得分、各題答案、解析及教材段落連結。
- 重新作答會重新洗牌單選、配對及圖片題的選項，並清除前次回饋。
- 填空會忽略全形／半形與空格差異；接受「智慧宮」、「研究東西方學問的智慧宮」及「智慧宫」。
